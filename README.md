# One-Line Office Joke

An entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162?utm_source=github&utm_medium=readme&utm_campaign=u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) bounty on make.fun.

`main.ts` writes a single original one-line joke about office life to `/output/entry.txt` — no network, no dependencies, fully deterministic. The joke was picked from ten original candidates scored against the judge's five criteria (office joke, funny surprise payoff, one line, fresh specific detail, clear on first read), then revised twice for tighter wording.

## Run

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (1–200 characters, single line, no trailing newline). Running it twice produces byte-identical output.

## The joke

> HR says our open-plan office "encourages collaboration" — which is how I know Dave's divorce lawyer's first name.
